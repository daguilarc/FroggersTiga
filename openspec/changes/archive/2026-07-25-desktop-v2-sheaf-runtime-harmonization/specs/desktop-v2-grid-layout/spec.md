Desktop v2 layout authority SHALL place dual scope panels and module-section parameter grids on the Application surface, relocate transport and global-command chrome beside the scopes, and fit remaining modules (no Random S&H section) at 1280×920 without vertical scroll of the parameter surface. Task 7.1 records the arrangement that satisfies this requirement before tasks 7.2–7.7 land.

- **WHEN** the Application surface lays out at 1280×920
- **THEN** transport and global-command controls occupy space to the right of the scope panels
- **THEN** module-section encoders do not sit under a carousel header band
